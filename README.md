# Учебный сад — рабочий прототип

Статический сайт на HTML, CSS и JavaScript. Библиотеки и сборка не нужны.

## Что работает

- В меню только Skola → Matemātika. Классы 1–12 и темы открываются в центре.
- Один урок: 6 класс → Daļas. Остальные классы пока показывают заглушку.
- Основной язык — латышский. Средняя кнопка мыши по предложению переводит только его на русский на 10 секунд. Затем оно возвращается на латышский. Повторный средний клик продлевает перевод. Подписи также переводятся этим способом.
- Палитра справа сверху открывает полноэкранный выбор: 10 предварительных пастельных тем, белая и тёмная. Выбор сохраняется.
- Прогресс показан только фигурами с процентами внутри. Правый клик по фигуре открывает количество пройденных тем и полоску. Обычный клик по фигуре открывает то же окно для клавиатуры и сенсорного экрана. Название класса открывает темы.
- У 6 класса одна тема: 0/1 или 1/1. У остальных 0/0, поскольку темы ещё не добавлены.
- Кнопка ⓘ открывает описание. Галочка прохождения сохраняется.
- Фенечка (кролик, девочка) и Жулик (лис, мальчик) остаются внизу слева при закрытии меню. У каждого отдельно показаны еда и вода. Посередине — общие вкусняшки.
- Правильный ответ в задании на дроби даёт одну вкусняшку. За повторное решение того же задания награда не начисляется. Галочка прочтения не даёт награду.

Питомцы пока представлены эмодзи, миски декоративные. Кормление, перетаскивание еды, одежда и анимации ещё не реализованы.

## Файлы

- index.html — разметка.
- css/style.css — оформление.
- js/app.js — переводы, темы, навигация и сохранение.
- .nojekyll — отключение обработки Jekyll на GitHub Pages.

## Запуск и GitHub Pages

Открой index.html. Для надёжного сохранения используй локальный сервер, например Live Server в VS Code, или GitHub Pages.

1. Создай репозиторий на GitHub.
2. Распакуй архив и загрузи содержимое папки learning-site в корень репозитория. index.html должен лежать в корне. Сохрани папки css, js и файл .nojekyll.
3. В Settings → Pages выбери Deploy from a branch, main и / (root), нажми Save.
4. После публикации открой адрес, который покажет GitHub Pages.

Все пути относительные. Прогресс, тема и награды хранятся в localStorage этого браузера и не синхронизируются между устройствами. Очистка данных сайта удалит их. Ключ learning-garden-v1 сохраняет прогресс из предыдущего прототипа.

## Как менять

Тексты находятся в translations в js/app.js: предложения LV/RU должны соответствовать по порядку. Палитры — в массиве themes того же файла; первые десять предварительные. Разметка — в index.html, оформление — в css/style.css.

## Проверить вручную

Переведи одно из соседних предложений средней кнопкой и подожди 10 секунд. Выбери белую и тёмную темы, обнови страницу. Открой 6 класс и урок, поставь галочку, вернись к классам, нажми правой кнопкой по фигуре: должно быть 1 из 1. Реши задание: повторный правильный ответ не должен увеличивать награду. Закрой меню — оба питомца должны остаться видимыми.

## Телефон

На узком экране меню открывается кнопкой и закрывается нажатием на затемнённую область. Питомцы остаются в нижней панели; под неё зарезервировано место. Кнопки увеличены для касания, темы отображаются в две колонки. Удерживай палец на предложении примерно полсекунды для перевода на 10 секунд; движение пальцем отменяет удержание и позволяет прокручивать страницу. Касание фигуры открывает прогресс. В горизонтальном положении нижняя панель становится компактнее.

## Палитры и фигуры прогресса

Доступны десять пастельных тем: розово-лавандовая, синий иней, светлая мальва, пшеничная, светло-мятная, сливочная, светло-бирюзовая, лососевая, очень светлая жёлто-зелёная и светло-карамельная. Белая и чёрная расположены отдельно под ними. Названия в интерфейсе латышские; удержание на телефоне или средний клик переводит название на русский.

У классов 12 разных фигур: круг, квадрат, ромб, треугольник, пятиугольник, шестиугольник, семиугольник, восьмиугольник, звезда, сердце, цветок и щит. Цвет контура и заливки следует выбранной теме, процент находится внутри. Подробности по-прежнему открываются правым кликом или касанием фигуры.
